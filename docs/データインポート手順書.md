# 📊 FXシミュレーター データインポート手順書

最終更新日: 2024年1月26日

## 📌 概要

FXシミュレーターでは、過去の為替データを使用してトレーディングの練習を行います。
本書では、データの準備からインポートまでの詳細な手順を説明します。

## 🎯 データインポート方法の選択

### 方法1: サンプルデータ生成（推奨）
- **用途**: 開発・テスト・デモ
- **所要時間**: 約5秒
- **データ品質**: シミュレートされた現実的な価格変動
- **メリット**: すぐに使える、設定不要

### 方法2: HistData.comからの実データ
- **用途**: 本格的なバックテスト、本番環境
- **所要時間**: 30分〜1時間
- **データ品質**: 実際の市場データ
- **メリット**: リアルな価格変動、信頼性が高い

## 📈 方法2: HistData.comからの実データ取得

### 前提条件
- HistData.comのアカウント（無料）
- unzipコマンドが使用可能なこと（macOS/Linux）

### 手順

#### 1. HistData.comからデータをダウンロード

##### 1.1 ダウンロードURLリストを取得
```bash
node scripts/downloadHistData.js
```

このコマンドで以下のようなURLリストが表示されます：

```
📋 Manual Download URLs:

USDJPY:
  2021: http://www.histdata.com/download-free-forex-historical-data/?/ascii/1-minute-bar-quotes/dat_ascii_usdjpy_m1/2021
       Save as: temp/histdata/USDJPY_2021.zip
  2022: http://www.histdata.com/download-free-forex-historical-data/?/ascii/1-minute-bar-quotes/dat_ascii_usdjpy_m1/2022
       Save as: temp/histdata/USDJPY_2022.zip
  [...]
```

##### 1.2 各URLからファイルをダウンロード
1. ブラウザで各URLを開く
2. ダウンロードページで「Download」ボタンをクリック
3. ZIPファイルを `temp/histdata/` フォルダに保存
4. ファイル名を指定された名前に変更（例: `USDJPY_2021.zip`）

#### 2. ダウンロードしたデータを変換

##### 2.1 tempフォルダを作成
```bash
mkdir -p temp/histdata
```

##### 2.2 ダウンロードしたZIPファイルを配置
```bash
# ダウンロードフォルダから移動
mv ~/Downloads/HISTDATA_COM_ASCII_USDJPY_M1_2021.zip temp/histdata/USDJPY_2021.zip
# 他のファイルも同様に配置
```

##### 2.3 変換スクリプトを実行
```bash
node scripts/downloadHistData.js
```

正常に実行されると：
```
📬 Found 18 ZIP files in temp directory.
Starting conversion process...

💱 Processing USDJPY
📦 Unzipping temp/histdata/USDJPY_2021.zip...
✅ Unzipped successfully
📊 Converting 371520 minutes data to daily...
✅ Converted to 260 daily records
[...]
```

#### 3. データ形式について

##### HistDataの元形式（1分足）
```csv
20210101 170000,108.730,108.732,108.729,108.732,0
20210101 170100,108.732,108.736,108.732,108.735,0
```

##### 変換後の日足形式
```csv
Date,Open,High,Low,Close
20210101,108.730000,108.756000,108.720000,108.745000
20210104,108.750000,108.890000,108.680000,108.850000
```

### トラブルシューティング

#### ZIPファイルが解凍できない場合
```bash
# 手動で解凍
cd temp/histdata
unzip USDJPY_2021.zip
# CSVファイルの名前を確認して、スクリプトで指定された名前に変更
mv DAT_ASCII_USDJPY_M1_2021.csv DAT_ASCII_USDJPY_M1_2021.csv
```

#### データが多すぎる場合
1分足データは膨大なため、日足のみが必要な場合は、HistData.comで直接日足データを選択してダウンロードすることも可能です。

## 🏃 アプリでのデータインポート

### 自動インポートの仕組み

1. **初回起動時の処理フロー**
```
アプリ起動
  ↓
SplashScreen表示
  ↓
AsyncStorageチェック（isDataImported）
  ↓
未インポートの場合 → DataImportScreen表示
  ↓
CSVImporter実行（6通貨ペア順次処理）
  ↓
SQLiteデータベースに保存
  ↓
完了フラグ設定
  ↓
MainTabへ遷移
```

2. **進捗表示**
- 各通貨ペアごとの進捗バー
- 全体の進捗パーセンテージ
- リアルタイム更新

### データのリセット方法

#### 方法1: アプリデータをクリア
```bash
# Android
adb shell pm clear com.fxsimulator

# iOS（シミュレータ）
xcrun simctl uninstall booted com.fxsimulator
```

#### 方法2: AsyncStorageをリセット
```javascript
// デバッグコンソールで実行
import AsyncStorage from '@react-native-async-storage/async-storage';
AsyncStorage.removeItem('isDataImported');
```

#### 方法3: データベースを直接削除
```javascript
// DatabaseInit.tsで実行
await db.executeSql('DROP TABLE IF EXISTS price_data');
await db.executeSql('DELETE FROM price_data');
```

## ❓ よくある質問

### Q1: データインポートが失敗する
**A:** 以下を確認してください：
- CSVファイルが正しい場所に配置されているか
- ファイル名が正しいか（大文字小文字も含む）
- CSVファイルの形式が正しいか

### Q2: インポート済みなのに再度インポートしたい
**A:** アプリのデータをクリアするか、AsyncStorageの`isDataImported`フラグを削除してください。

### Q3: 特定の期間のデータだけ欲しい
**A:** generateSampleData.jsのstartDateとendDateを調整してください。

### Q4: リアルタイムデータを使いたい
**A:** 現在の実装は過去データのみ対応です。リアルタイムデータのサポートは将来の機能拡張で検討中です。

### Q5: データの精度を上げたい
**A:** HistData.comから実データを取得することで、より正確な市場データを使用できます。
