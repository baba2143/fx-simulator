## 📱 プラットフォーム別動作確認

### iOS Simulator

#### 準備
```bash
# CocoaPodsの依存関係インストール
cd ios
pod install
cd ..
```

#### 起動方法
```bash
# デフォルトSimulatorで起動
npx react-native run-ios

# 特定のデバイスで起動
npx react-native run-ios --simulator="iPhone 14 Pro"

# 利用可能なSimulator一覧
xcrun simctl list devices
```

#### よくある問題と解決方法

**問題**: `No bundle URL present`
```bash
# Metro Bundlerを再起動
npx react-native start --reset-cache
```

**問題**: `Unable to find a simulator`
```bash
# Xcodeを開いてSimulatorをダウンロード
open -a Xcode
# Window > Devices and Simulators
```

### Android Emulator

#### 準備
```bash
# Android Studioでエミュレータ作成
# 推奨: Pixel 6, API 33 (Android 13)
```

#### 起動方法
```bash
# エミュレータリスト確認
emulator -list-avds

# エミュレータ起動
emulator -avd Pixel_6_API_33

# アプリ起動
npx react-native run-android
```

#### よくある問題と解決方法

**問題**: `INSTALL_FAILED_INSUFFICIENT_STORAGE`
```bash
# エミュレータのストレージをクリア
# Android Studio > AVD Manager > Wipe Data
```

**問題**: `Could not connect to development server`
```bash
# ADBリバースを設定
adb reverse tcp:8081 tcp:8081
```

## 🚨 緊急時の対応

### アプリがクラッシュする場合

```bash
# 1. クリーンインストール
rm -rf node_modules ios/Pods
npm install
cd ios && pod install && cd ..

# 2. キャッシュクリア
npx react-native start --reset-cache

# 3. デバイスのアプリ削除・再インストール
```

### データが表示されない場合

```bash
# 1. サンプルデータ再生成
node scripts/generateSampleData.js

# 2. AsyncStorageクリア
# デバッグコンソールで:
AsyncStorage.clear()

# 3. アプリ再起動
```

### ビルドエラーの場合

```bash
# iOS
cd ios
pod deintegrate
pod install
cd ..

# Android
cd android
./gradlew clean
cd ..
```
