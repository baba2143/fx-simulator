# 🚀 データインポート クイックスタートガイド

## 🎯 最速セットアップ（30秒で完了）

### ステップ1: データ生成
```bash
cd /Users/makotobaba/Desktop/FXシミュレーター
node scripts/generateSampleData.js
```

### ステップ2: アプリ起動
```bash
# Android
npx react-native run-android

# iOS
npx react-native run-ios
```

**以上で完了！** アプリが起動し、自動的にデータがインポートされます。

### Android
```bash
adb shell pm clear com.fxsimulator
```

### iOS
```bash
# シミュレータの場合
xcrun simctl uninstall booted com.fxsimulator
```

## ⚡ トラブルシューティング

### データが表示されない
1. アプリを完全に終了
2. データを再生成: `node scripts/generateSampleData.js`
3. アプリを再起動

### インポートエラー
- CSVファイルの存在を確認: `ls android/app/src/main/assets/data/`
- 権限を確認: `chmod 644 android/app/src/main/assets/data/*.csv`
