# CSR (Certificate Signing Request) 作成手順

## ❌ エラーの原因

「Invalid CSR - Select a valid Certificate Signing Request」エラーは、以下のいずれかが原因です:

1. CSRファイルの作成手順が間違っている
2. 既存の証明書と競合している
3. キーチェーンの権限問題

---

## ✅ 正しい CSR 作成手順

### **Step 1: キーチェーンアクセスを開く**

```bash
# 以下のいずれかの方法で開く

【方法 1】Spotlight 検索
Command + Space → "キーチェーンアクセス" と入力 → Enter

【方法 2】Finder から
Finder → アプリケーション → ユーティリティ → キーチェーンアクセス.app

【方法 3】Launchpad から
Launchpad → その他 → キーチェーンアクセス
```

キーチェーンアクセスのメニューバーから:

```
  → 証明書アシスタント
    → 認証局に証明書を要求...
```

### **Step 3: 証明書情報を入力**

#### **3-1. 証明書情報画面**

```
┌──────────────────────────────────────────────┐
│ 認証局に証明書を要求                            │
├──────────────────────────────────────────────┤
│                                              │
│ ユーザのメールアドレス:                         │
│ ┌──────────────────────────────────────┐    │
│ │ your-email@example.com                │    │
│ └──────────────────────────────────────┘    │
│                                              │
│ 通称:                                        │
│ ┌──────────────────────────────────────┐    │
│ │ FX Simulator Distribution             │    │
│ └──────────────────────────────────────┘    │
│                                              │
│ CAのメールアドレス:                            │
│ ┌──────────────────────────────────────┐    │
│ │ (空欄のまま)                           │    │
│ └──────────────────────────────────────┘    │
│                                              │
│ 要求の処理:                                   │
│ ● ディスクに保存                              │  ← 必須
│ ☐ CAにメールで送信                           │
│                                              │
│ ☑ 鍵ペア情報を指定                            │  ← 必須チェック
│                                              │
│           [続ける]                           │
└──────────────────────────────────────────────┘
```

**📝 入力内容**:
- **ユーザのメールアドレス**: あなたのメールアドレス
  - 例: `makotobaba@example.com`
- **通称**: わかりやすい名前
  - 例: `FX Simulator Distribution`
- **CAのメールアドレス**: **空欄のまま**
- **要求の処理**:
  - ✅ **ディスクに保存** を選択
  - ☑ **鍵ペア情報を指定** に **必ずチェック**

**⚠️ 重要**: 「鍵ペア情報を指定」にチェックを入れないと、後でエラーになります。

---

#### **3-2. 保存場所を選択**

[続ける] をクリックすると、ファイル保存ダイアログが表示されます:

```
保存場所: デスクトップ
ファイル名: CertificateSigningRequest.certSigningRequest

[保存] をクリック
```

---

#### **3-3. 鍵ペア情報を指定**

次の画面で鍵のサイズとアルゴリズムを選択:

```
┌──────────────────────────────────────────────┐
│ 鍵ペア情報                                     │
├──────────────────────────────────────────────┤
│                                              │
│ 鍵のサイズ:                                   │
│ ┌──────────────────────────────────────┐    │
│ │ ● 2048 ビット                         │    │  ← 推奨
│ │ ○ 4096 ビット                         │    │
│ └──────────────────────────────────────┘    │
│                                              │
│ アルゴリズム:                                 │
│ ┌──────────────────────────────────────┐    │
│ │ ● RSA                                 │    │  ← 必須
│ │ ○ EC                                  │    │
│ └──────────────────────────────────────┘    │
│                                              │
│           [続ける]                           │
└──────────────────────────────────────────────┘
```

**📝 選択内容**:
- **鍵のサイズ**: `2048 ビット` (推奨)
- **アルゴリズム**: `RSA` (必須)

[続ける] → [完了] をクリック

---

### **Step 4: CSR ファイルの確認**

デスクトップに以下のファイルが作成されます:

```
📄 CertificateSigningRequest.certSigningRequest
```

**ファイルサイズ確認**:
```bash
ls -lh ~/Desktop/CertificateSigningRequest.certSigningRequest

# 出力例:
# -rw-r--r--  1 makotobaba  staff   1.0K Oct  3 15:30 CertificateSigningRequest.certSigningRequest
```

正常なCSRファイルは **約 1KB** のサイズです。

## 🔄 Apple Developer Portal での使用

### **Certificate 作成時にアップロード**

1. **Apple Developer Portal にアクセス**
   - https://developer.apple.com/account
   - Certificates, Identifiers & Profiles

2. **Certificates → "+" ボタン**

3. **iOS Distribution を選択**
   ```
   □ Apple Distribution
   または
   □ iOS Distribution (App Store and Ad Hoc)

   [Continue]
   ```

4. **CSR ファイルをアップロード**
   ```
   Choose File... をクリック

   → デスクトップから
     CertificateSigningRequest.certSigningRequest
     を選択

   [Continue]
   ```

5. **証明書のダウンロード**
   ```
   [Download] をクリック

   ダウンロードされたファイル:
   distribution.cer (約 1-2KB)
   ```

6. **証明書をインストール**
   ```
   ダウンロードした distribution.cer を
   ダブルクリック

   → キーチェーンに自動的に追加されます
   ```

## 🔍 トラブルシューティング

### **Problem 1: "Invalid CSR" エラーが出る**

**原因**: 鍵ペア情報の指定を忘れた

**解決方法**:
```
1. 最初からやり直す
2. 「鍵ペア情報を指定」に必ずチェック
3. 鍵のサイズ: 2048 ビット
4. アルゴリズム: RSA
```

---

### **Problem 2: CSR ファイルが作成されない**

**原因**: ディスクに保存を選択していない

**解決方法**:
```
要求の処理で:
● ディスクに保存 を選択
```

---

### **Problem 3: キーチェーンの権限エラー**

**原因**: キーチェーンがロックされている

**解決方法**:
```bash
# キーチェーンアクセスで
左側のキーチェーン一覧から:
● ログイン を選択
● システム ではなく

ロックアイコンをクリックして解除
```

---

### **Problem 4: 既存の証明書と競合**

**原因**: 同じ名前の証明書が既に存在

**解決方法**:
```
キーチェーンアクセス → 証明書カテゴリ

既存の "iPhone Distribution" を確認
期限切れや不要なものを削除:
右クリック → 削除
```

## ✅ 成功の確認

### **CSR ファイルが正常に作成された場合**

1. **ファイルサイズが 1KB 前後**
   ```bash
   ls -lh ~/Desktop/CertificateSigningRequest.certSigningRequest
   # 約 1.0K であること
   ```

2. **ファイルの中身を確認** (オプション)
   ```bash
   cat ~/Desktop/CertificateSigningRequest.certSigningRequest

   # 以下のような内容が表示されるはず:
   # -----BEGIN CERTIFICATE REQUEST-----
   # MIICijCCAXICAQAwRTELMAkGA1UEBhMCQVUxEzARBgNVBAgMClNvbWUtU3RhdGUx
   # ...
   # -----END CERTIFICATE REQUEST-----
   ```

3. **キーチェーンに秘密鍵が作成された**
   ```
   キーチェーンアクセス → 鍵カテゴリ

   "FX Simulator Distribution" という名前の
   秘密鍵が存在することを確認
   ```
